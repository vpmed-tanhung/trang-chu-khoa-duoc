CHỈ LÀM 3 BƯỚC

1. Giải nén file ZIP này.
2. Tải nguyên cấu trúc bên trong thư mục đã giải nén lên nhánh main
   của repository GitHub trang-chu-khoa-duoc, gồm cả thư mục ẩn “.github”.
3. Bấm “Commit changes”.

XONG. Không chạy file BAT, PowerShell hay Python.
GitHub Actions tự kiểm tra nguồn và cập nhật dữ liệu mỗi ngày lúc 06:00 sáng
theo giờ Việt Nam. Website không có nút cập nhật thủ công.
Đường dẫn chính sau khi cập nhật (theo file CNAME):
https://hotrolamsang.io.vn/#pharmacovigilance

Manifest và Service Worker dùng đường dẫn tương đối nên vẫn hỗ trợ đường dẫn
GitHub Pages của repository khi cần kiểm tra trước khi DNS/CNAME hoạt động.

LƯU Ý: Cần bật Settings → Actions → General → Workflow permissions →
“Read and write permissions” một lần để workflow có thể lưu dữ liệu mới.
